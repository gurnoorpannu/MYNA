# Demo video script (≤ 5 min, one take, no edits)

Required order: **(a)** teach one flow by voice + taps → **(b)** replay with the exact command → **(c)** replay with a paraphrase → **(d)** replay with a changed blank → **(e)** the assistant asking a question when stuck.

We use **Amazon** for (a)–(d): it is fully automatic end to end (Zomato's *Add item* button needs a finger — see limitations). **(e)** uses a vague command and a closed/stuck case.

## Before recording (10 min)

- [ ] Amazon cart **empty**; Amazon logged in, delivery address set
- [ ] Delete old Amazon automations in **Teach**, so (a) creates the only one
- [ ] Phone: **Do Not Disturb** on, **Stay awake** on, media volume ~60% (MYNA speaks), battery > 50%
- [ ] MYNA open on **Home**, accessibility on, microphone allowed
- [ ] Screen recorder with **microphone audio** on (voice + MYNA's replies must be audible)
- [ ] Quiet room; say commands clearly, facing the phone
- [ ] Dry run once, then empty the cart again

## Shot list

| Time | Part | Do | Say / show |
|---|---|---|---|
| 0:00–0:10 | intro | Home screen | "This is MYNA. I'll teach it once, then just say it." |
| 0:10–1:30 | **(a) teach** | **Teach** tab → 🎤 → pick **Amazon** → **Show me once** → search `s25 ultra phone case` → Go → open a case → scroll → **Add to cart** → **Cart** tab → **Proceed to checkout** | Say: *"Add a phone case for my S25 Ultra to my Amazon cart."* The 🔒 banner stops recording at payment; MYNA says *"Learned: …"*. Open **Steps** for 3 s to show the step list. |
| 1:30–1:40 | reset | back to MYNA; empty cart shown quickly **or** skip (Amazon adds another case — fine) | — |
| 1:40–2:20 | **(b) exact** | **Home** → tap mic | *"Add a phone case for my S25 Ultra to my Amazon cart."* → runs → 🔒 *"Your turn."* |
| 2:20–3:00 | **(c) paraphrase** | back to MYNA → mic | *"Put an S25 Ultra phone cover in my Amazon cart."* → runs → 🔒 |
| 3:00–3:50 | **(d) changed blank** | mic | *"Add a laptop stand to my Amazon cart."* → MYNA: *"Which item? … or say none"* → say *"none"* → adds a **laptop stand** → 🔒 |
| 3:50–4:40 | **(e) asks when unsure / stuck** | mic | *"Order pizza."* → *"Did you mean: order Margherita from Domino's — like last time?"* → say *"yes"* → if Domino's is closed MYNA stops: *"Domino's Pizza isn't taking orders right now…"*; if open, it runs and **asks you to tap Add item**. Then: *"Did the last run work?"* → one-sentence report. |
| 4:40–4:55 | close | **History** tab → tap the last run to show its steps and reason | "Every step, every reason, and it never touches payment." |

## If something goes wrong mid-take

Keep recording. MYNA stops with a spoken reason (that *is* part (e)). Say *"did the last run work?"* to show the report, then continue with the next part.
